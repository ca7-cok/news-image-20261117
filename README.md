One image summing up the world's news of **Tuesday 17 November 2026**: Ukraine strikes the Crimean Bridge again, tankers hit mines near Hormuz, the first Xi–Trump–Putin summit is confirmed for Shenzhen, Trump joins Quad talks in Manila, a cyberattack hits 178 major websites, and the ULA Vulcan rocket fails after liftoff.

`render.py` draws the 1024×1024 infographic with Pillow (run locally to produce `entry.png`); `main.py` is the entry point the grader runs — standard library only, it copies `entry.png` to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
